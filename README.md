## Execution Instructions

### 1. Assemble the Program
```bash
python3 Capstone/assembler.py Capstone/Box.asm
```
This produces `Capstone/Box.hack` and `Capstone/symbols.txt`.

### 2. CPU Emulator Execution
1. Open the CPU Emulator (`CPUEmulator.sh`).
2. Load `Capstone/Box.hack`.
3. Set speed to Fast and click Run.
4. Press and hold any key in the keyboard area: the 16×20 black box appears at row 36.
5. Release the key: the box disappears immediately.

### 3. Hardware Simulator Verification (Part A)

